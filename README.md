# Семейный планировщик путешествий

Выпускной проект Пановой Анны по курсу «Профессия Вайб-кодер».

![Обложка приложения — ИИ-иллюстрация путешествий](web/static/images/travel-hero.png)

Telegram-бот и веб-кабинет помогают составить поездку на 1–14 дней: выбрать направление, учесть состав группы и возраст детей, интересы, темп, погоду и бюджет. Путешествовать можно и без детей. Маршрут сохраняется в личном кабинете, отображается на карте и выгружается в PDF с чек-листом.

## Возможности

- Создание городской или региональной поездки через Telegram и веб-кабинет.
- Проверка структуры ответа ИИ, дат, времени, бюджета, повторов и географии мест.
- Программа и свободные дни при недостатке подходящих проверенных мест — без выдуманного заполнения всех дней.
- Изменение одного дня: остальные дни сохраняются; отклонённая правка не заменяет старый маршрут.
- Карта, групповой бюджет, PDF и общий для бота и кабинета чек-лист.
- Память предпочтений и отзывов с разделением по пользователю и направлению.
- Напоминания в Telegram, управление памятью и подтверждённое удаление своих активных данных.
- Необязательные ИИ-обложки, сохранение результата и возможность скрыть неудачную иллюстрацию.
- Закрытый демонстрационный доступ по личным временным приглашениям.

Это помощник для предварительного планирования, а не сервис бронирования. Карта подтверждает сведения о месте в источнике, но не актуальные часы работы, билеты и цены. Неизвестная цена не считается бесплатным входом. Дальняя погода обозначается как исторический ориентир. ИИ-обложка — иллюстрация, а не фотография или подтверждение вида места.

## Как устроен проект

Python 3.12, FastAPI, pyTelegramBotAPI, SQLite, Pydantic, ReportLab, APScheduler; веб-интерфейс — HTML/CSS/JavaScript и Leaflet. YandexGPT используется для AI-операций и эмбеддингов, Pinecone — для памяти. Географические и погодные данные поступают из внешних сервисов. Обложки используют отдельный Yandex Cloud Images API.

Бот и веб работают отдельными процессами и используют одну базу. Веб запускается с одним worker. Поддерживается локальный запуск и Docker Compose.

## Локальный запуск

Нужны Python 3.12, интернет, собственный Telegram-бот и ключи Yandex AI Studio и Pinecone. Ниже команды для PowerShell; выполняйте их из корня проекта.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
```

Заполните `.env` в редакторе. Не публикуйте этот файл, значения ключей, базу и ссылки входа.

| Настройка | Что указать |
| --- | --- |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_MODEL_URI` | Свой ключ, каталог и доступную модель YandexGPT |
| `YANDEX_EMBEDDING_DOC_URI`, `YANDEX_EMBEDDING_QUERY_URI` | URI моделей эмбеддингов с вашим ID каталога |
| `PINECONE_API_KEY`, `PINECONE_INDEX_NAME` | Свой ключ и индекс с размерностью 256 и метрикой cosine |
| `TELEGRAM_BOT_TOKEN` | Токен собственного бота из BotFather |
| `ACCESS_MODE`, `ACCESS_OWNER_IDS` | `invite` и свой числовой Telegram ID; не `@username` и не токен |
| `WEB_BASE_URL`, `WEB_SESSION_SECRET` | Локально `http://127.0.0.1:8000` и случайный секрет не менее 32 символов |
| `CITY_CANDIDATES_FIRST`, `CITY_DETERMINISTIC_SCHEDULE` | Обе настройки `1` для городского расписания по проверенному набору мест, рассчитанного сервером |
| `REMINDER_TZ`, `REMINDER_DAYS_BEFORE` | Часовой пояс и число дней до первого напоминания |

Шаблон `.env.example` включает закрытый доступ и оба городских переключателя, но оставляет генерацию изображений выключенной. Пустой список владельцев закрывает доступ до настройки. При отсутствии `ACCESS_MODE` в старой конфигурации код сохраняет режим `open`; само обновление исходников не закрывает старый экземпляр. Без городских переключателей код использует прежнюю ветку генерации. Региональная ветка этими переключателями не меняется.

Для создания локального секрета веб-сессии без вывода его значения:

```powershell
.\.venv\Scripts\python.exe setup_web.py
```

Скрипт дополняет `.env` локальными настройками. Для публичного сервера нужны HTTPS, соответствующий `WEB_BASE_URL` и `WEB_COOKIE_SECURE=true`. Если подходящего индекса Pinecone ещё нет, `setup_pinecone.py` может создать его и записать имя в `.env`: это отдельное действие во внешнем сервисе, а не обязательная часть установки зависимостей.

Запустите два процесса в двух терминалах:

```powershell
.\.venv\Scripts\python.exe web_app.py
```

```powershell
.\.venv\Scripts\python.exe bot.py
```

В личном чате с ботом отправьте `/start`, затем `/web` и откройте одноразовую ссылку. Локальный адрес работает только на том компьютере, где запущен сервер. Для других устройств нужен публичный HTTPS-адрес. `/health` проверяет веб-сервер, но не доступность всех внешних API. Не запускайте одновременно локальный и серверный бот с одним токеном.

## Демонстрационный доступ и расходы

Владелец создаёт приглашение в личном чате командой `/invite_one` или `/invite`. Новая ссылка предназначена **для одного проверяющего, на пять попыток создания или ИИ-изменения поездки за весь срок**. По умолчанию срок — **семь дней от создания**, не от активации; `/invite_one 3` задаёт три дня. Допустимо 1–30 дней. Все пять попыток можно использовать в один день.

Ссылка закрепляется за первым активировавшим её Telegram-аккаунтом. Передавайте её лично: до активации пересланной ссылкой может воспользоваться другой человек. Не помещайте приглашение в GitHub, публичное видео и скриншоты.

| Квота | На кого и как действует |
| --- | --- |
| 5 маршрутных попыток | На одного гостя за весь срок нового приглашения, вместо суточного `DAILY_LIMIT` |
| `DAILY_LIMIT=3` | На владельца и каждого пользователя открытого режима за местный день `REMINDER_TZ` |
| `ACCESS_GLOBAL_ROUTE_DAILY_LIMIT=12` | На всех, включая владельца, за сутки UTC в режиме `invite` |
| 3 попытки обложек и 3 операции памяти | Отдельные квоты гостя за срок доступа |
| `IMAGE_GENERATION_DAILY_LIMIT=10` | Общий предел попыток обложек приложения за сутки UTC |

Просмотр поездок и PDF не расходуют маршрутные попытки. Принятая попытка не возвращается при последующей ошибке. Одна маршрутная операция может включать несколько обращений к модели, поэтому квота операций — не денежный бюджет. Лимиты и уведомления об оплате дополнительно настраиваются у провайдера.

`/invites` показывает выданные приглашения и позволяет их отозвать. Повторный вход по той же ссылке не обнуляет расход. После исчерпания попыток владелец может выдать новое личное приглашение. При отзыве или истечении срока закрывается доступ, включая уже открытый кабинет; отправленный ранее запрос провайдеру отменить нельзя. После проверки отзовите приглашения и оставьте закрытый режим.

## Обложки

Включаются отдельно: `IMAGE_GENERATION_ENABLED=1`. Ключу нужны права на изображения; `YANDEX_ART_API_KEY` необязателен, при его отсутствии используется `YANDEX_API_KEY`.

После сохранения новой веб-поездки обложка создаётся фоновым заданием. Для старых поездок и поездок из Telegram есть кнопка в кабинете. Чтение готовой обложки и статуса не запускает платную генерацию. При ошибке, потере ответа или перезапуске автоматического платного повтора нет.

Генератор получает только направление, страну и календарные даты, а не семейные данные и пожелания. Изображение хранится приватно в `IMAGE_CACHE_DIR` и доступно владельцу поездки. При удалении поездки доступ закрывается; физическая очистка оставшихся файлов обложек пока не автоматизирована. Неудачную иллюстрацию можно скрыть без нового запроса к ИИ.

## Команды бота

`/start`, `/help` — помощь; `/plan` — новая поездка; `/trips` — сохранённые поездки; `/web` — вход в кабинет. В меню поездки доступны изменение дня, PDF и чек-лист. `/memory` — память предпочтений; `/delete_data` — подтверждённое удаление своих активных данных. Команды приглашений доступны только владельцу.

Напоминания требуют постоянно работающего бота и доступного Telegram. Один экземпляр проверяет расписание каждые пять минут: по умолчанию за три дня до поездки в 10:00, накануне в 18:00 и в дни поездки в 08:00 по `REMINDER_TZ`.

## Автономные проверки без платных запросов

Для тестов дополнительно нужны Node.js 24+ и зависимости разработки. Используйте защищённый runner: он проверяет временную копию исходников, не копирует `.env` и пользовательские данные, запрещает внешнюю сеть и запись вне временной папки. Тесты не запускают приложение и не должны обращаться к платному AI.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -X utf8 -B tools/run_offline_checks.py
```

В общий запуск входят Python-тесты, UI-тесты, региональные проверки и автономные сценарии. Ошибка, пропущенный тест, нарушение изоляции или изменение проверяемого снимка не дают успешного результата. Допустим частичный запуск с `--only unit`, `node`, `smoke` или `guard`. Итог относится к автономной регрессии, а не доказывает доступность сервисов или успешность любой реальной поездки.
