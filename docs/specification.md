# Базовое техническое задание

Цель проекта — помочь семье или группе взрослых составить и сохранить план путешествия с учётом дат, интересов, возраста детей, времени и бюджета.

Полная авторская версия [технического задания в Word](submission/specification.docx) является основным документом для защиты. Этот файл даёт краткую навигацию по базовому объёму; дополнительные улучшения описаны [отдельно](tz-supplement.md).

## Основной пользовательский сценарий

1. Пользователь открывает Telegram-бота и заполняет анкету поездки.
2. Приложение получает маршрут от ИИ, проверяет обязательные условия и сохраняет результат.
3. Пользователь просматривает программу, бюджет, погодные сведения и чек-лист подготовки.
4. При необходимости изменяет выбранный день и получает обновлённый результат после проверок.
5. Сохранённая поездка доступна повторно; PDF можно взять с собой, а бот отправляет напоминания.

## Базовые требования

- Анкета направления, дат, состава группы, интересов, темпа и бюджета.
- Учёт возраста детей и отдельный сценарий для взрослых без детей.
- План по дням с конкретными местами и ориентировочными расходами.
- Проверки структуры, расписания, повторов и допустимого бюджета.
- Погодные сведения с обозначением ограничений источника.
- Сохранение поездок, изменение выбранного дня, чек-лист и PDF.
- Память предпочтений пользователя и подготовительные напоминания.
- Хранение настроек сервисов вне публичного исходного кода.

## Границы

План — рекомендация для подготовки, а не продажа туристической услуги. Поиск и бронирование транспорта и жилья, оплата поездки и автоматический пересчёт валют не входят в базовый объём. Пользователь самостоятельно уточняет часы работы, цены, билеты и сезонную доступность.
